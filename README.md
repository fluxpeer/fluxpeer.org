# fluxpeer.org

Marketing and documentation site for [fluxpeer](https://github.com/fluxpeer) —
open-source, WireGuard-compatible, self-hostable mesh networking.

Built with **Svelte 5 + Vite + Tailwind CSS**, shipped as a static site. The UI
is internationalized; English and Simplified Chinese are fully translated, with
additional languages scaffolded.

## Develop

```bash
npm install
npm run dev      # dev server
npm run build    # → dist/  (static assets)
npm run preview  # preview the production build
```
